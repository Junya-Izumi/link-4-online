# Link 4 Online
This is an online game where you can play Connect 4.
I created this repository to learn WebSocket and Vue.js.

[ 日本語のREADMEはこちら ](./README.md)
## Tech stack
### Frontend
- TypeScript
- pnpm
- Vite
- Vue.js
- VueRouter
### Backend
- Python
- FastAPI
- Pydantic
- uvicorn
- websockets

## How to run (Docker)
### Dev
Start the development container using `compose.yml`
```bash
docker compose up
```
### Build
Start the built container using `production` scritp in `package.json`
```bash
pnpm production
```
